# v0.3.0-infra — Infrastructure & Docs (pre-icons)

This milestone finalizes the repository infrastructure and protocol documentation before adding canonical SVG icons.

## What’s included
- Protocol scaffolding: specs, lexicon registry, icon packs, tooling, and a static dictionary site.
- Static dictionary search (GitHub Pages-ready) that loads `lexicon/icon-index.json` and supports search by:
  - id
  - meaning (EN)
  - aliases (EN)
  - tags (EN)
- CI validation on push/PR:
  - Lexicon validation (pack IDs, uniqueness, required fields).
  - SVG validation (viewBox + `currentColor`/no hardcoded colors). SVG validation skips cleanly when no SVG icons exist yet.
- Tile authoring template (`templates/tile-template.svg`) to ensure consistent framing and safe area.

## Protocol decisions locked in this milestone
- Tiles are the canonical “words”: framed rounded-square tiles for the lexicon.
- Negation is expressed as `X + logic_no`. `logic_no` can also be used standalone as an answer.
- Context packs may include “fixed negations” (object + the same slash), but the core protocol stays minimal.
- Examples are normalized to the token format: `token + token` (no mixed syntaxes).

## What is NOT included yet
- No canonical icon SVG set is committed in `icons/svg/` (this is a pre-icons milestone).
- Merch layouts and city packs are intentionally out of scope until the canonical core icons are finalized.

## Next milestone

- Enforce additional SVG rules specific to the icon style once real icons exist.
- Generate black/white PNG exports from canonical SVGs and validate print-readability.
