# Pictiq v1.2.0 — Composer v0.1

Released 2026-09-13 after creator acceptance, local validation, CI, Pages verification, and public Composer route verification.

## Composer v0.1

Composer v0.1 is the first public human authoring surface for Pictiq. It lets a person write Pictiq messages through a browser UI instead of editing JSON, shorthand, SVG, or repository files directly.

The Composer workflow is:

PALETTE -> WORKSPACE -> RENDERER PREVIEW -> EXPORT.

## Highlights

- Static GitHub Pages Composer at `/composer/`.
- Palette search across ordinary concepts and Entity Symbols.
- Profile and context-pack filtering.
- Direct manipulation of Message Frames and tiles in the workspace.
- Browser Renderer preview and SVG export.
- Browser/Python Renderer parity guardrails.
- Canonical Message JSON import/export.
- `.pictiq` shorthand import/export.
- Legacy normalization for accepted compatibility migrations.
- Entity Symbol token support.
- Numeric notation support for number `50`.
- Token-local COLOR parameter controls.
- No AI, LLM, account, server, or cloud dependency.
