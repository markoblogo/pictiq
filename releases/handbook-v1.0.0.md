# Pictiq Handbook v1.0

The first complete illustrated handbook for Pictiq.

**Pictiq: A Visual Protocol for Short Messages**  
by Anton Biletskyi-Volokh

The handbook introduces Pictiq from first principles and shows how the protocol moves from a small icon lexicon into context packs, physical objects, storytelling, and machine-readable communication.

## Inside

- protocol rules and zero-intent communication
- Core lexicon and phrase patterns
- Paris context pack
- shirts and wallet cards
- Nightlife lighter
- luggage tag and personal lockscreen
- Alice in Wonderland visual communication experiment
- poetry and semantic-compression experiment
- computer vision and LLM concepts
