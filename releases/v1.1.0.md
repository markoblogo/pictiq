# Pictiq v1.1.0 — Architecture & Vocabulary Audit 2026-09

Released 2026-09-11 after local validation, CI, Pages verification, and human acceptance of the audit decisions.

## Architecture

- Closes the 2026-09 Architecture & Vocabulary Audit.
- Separates retained ordinary canonical identifiers from active ordinary semantic concepts.
- Keeps Entity Symbols in their own registry, separate from ordinary vocabulary.
- Adds machine-readable compatibility metadata for semantic migrations, deprecated composable vocabulary, and deferred legacy contextual hierarchy decisions.

## Vocabulary cleanup

- `drink_alcohol` is now the preferred active ID for ALCOHOL / ALCOHOLIC DRINK. Historical `need_bar` remains a compatibility alias and legacy SVG only. Artwork is unchanged.
- `place_home` is now the preferred active ID for HOME / SHELTER / SLEEPING PLACE / BUILDING. Historical `place_hotel` remains a compatibility alias and legacy SVG only. Artwork is unchanged.
- `place_fashion_shopping` is retained as a deprecated composable compatibility identifier. The preferred active expression is `place_shop + item_clothing`. It is not redrawn.
- `move_watercraft` is accepted as the broad water-transport primitive. `move_boat` remains a legacy contextual subtype; final compatibility action is deferred.
