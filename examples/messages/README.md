# Pictiq Message examples

These fixtures support [Pictiq Message Format v0.1](../../spec/PICTIQ_MESSAGE_SCHEMA.md) and [Pictiq Shorthand v0.1](../../spec/PICTIQ_SHORTHAND.md).

- `valid/*.json` are schema-valid canonical Pictiq Message JSON examples.
- `invalid/schema/*.json` are intentionally schema-invalid fixtures.
- `invalid/semantic/*.json` may be schema-valid but are intended to fail future registry-aware semantic validation.
- `*.pictiq` files are shorthand authoring examples, not canonical storage.

No fixture changes grammar semantics, vocabulary, icons, profiles, packs, entities, notation, renderer, Composer, tag, or release state.
