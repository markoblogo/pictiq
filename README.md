# Pictiq

Pictiq is a minimal visual protocol for short, universal messages across language barriers.
It is not meant for long texts. It is meant for pointing, quick signs, stickers, and simple phrases.
All lexicon icons are designed as framed tiles; the logo is not a tile.

## Core idea
- Pointing at an object icon is a valid message by default.
- Meaning is amplified using punctuation icons (`?` / `!`) and negation (slash overlay).
- Some nouns can act as actions depending on context (feet = go/walk, coins = pay/buy, transport = ride).

## Repository structure
- `/spec` — protocol specification (style rules + grammar)
- `/lexicon` — icon registry (metadata index)
- `/icons` — SVG icons (to be added)
- `/packs` — curated icon packs
