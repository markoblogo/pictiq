# Silhouette inputs (canonical)

These PNG files are canonical input silhouettes used to reproduce SVG generation.

Requirements:
- 1-bit black-on-white silhouettes
- no halftones / anti-aliased shading
- minimal details (avoid fragile micro-features)
- shape must fit safe-area after scaling in the tile pipeline

Naming rule:
- filename MUST equal `icon_id` (example: `logic_yes.png`)

Storage policy:
- only approved canonical inputs are stored here
- drafts and experiments must not be stored in this folder
