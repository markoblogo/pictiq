# Fixed Task Corpus

> Status: fixed corpus draft for pilot review. Use current accepted Pictiq vocabulary only.

## Training task — unscored

**T0. I need water.**

The experimenter may explain Composer mechanics during this task. Do not count this as a scored result.

## Scored tasks

Run these in fixed order for the initial tiny pilot.

| ID | Category | Participant-facing task | Notes |
| --- | --- | --- | --- |
| T1 | Direct basic | Make a message that asks for water. | Simple concept + question. |
| T2 | Negation | Make a message that means "no alcohol" or "no bar/drinking here." | Tests current NO behavior without deprecated IDs. |
| T3 | Composition | Make a message that means "I want food." | Should be built from current primitives rather than one specialized compound. |
| T4 | Multi-Frame | Make a two-part message: first "I need water"; second "thank you / good." | Tests Frame model. |
| T5 | Search / Context | Make a warning message about a slippery or uneven surface. | Concept is easier through Search or road context. |
| T6 | Number | Make a message that communicates the exact number 50. | Uses current numeric notation support only. |
| T7 | Entity Symbol | Make a message about Poseidon and water/sea. | Requires Odyssey context/entity selection. |
| T8 | Edit / Correct / Export | Start with a message that asks for water, then change it so it asks for food instead. Export the final result as SVG. | Tests correction and practical export. |

## Estimated duration

- Introduction: 2-4 minutes.
- Training: 2-4 minutes.
- Scored tasks: 12-17 minutes total.
- Debrief: 2-4 minutes.

Expected total: about 15-25 minutes.
