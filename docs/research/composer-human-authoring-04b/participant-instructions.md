# Participant Instructions

> Approximate introduction time: 2-4 minutes.

You are going to try Pictiq Composer. Pictiq is a small visual language/protocol made from reusable symbols. Symbols can be combined to make short messages.

The Composer has three main areas:

1. The Palette contains available symbols and labels. You may browse it, use Search, and use Context Packs.
2. The Message Workspace is where you arrange symbols. Click a symbol in the Palette to add it. Drag symbols to reorder them. Drag a symbol between Frames if it belongs somewhere else. The `+` button adds another Frame.
3. The right side shows the rendered Pictiq result and lets you export it.

A Frame is one short part of a message. A message can have one Frame or several Frames.

The goal is not artistic design. Please make a message that communicates the idea as well as you can using the available symbols. There may be more than one reasonable way to express an idea.

You may use visible labels, glosses, Search, Context Packs, and the Inspector. This test is not about memorizing icon meanings.

Optional think-aloud prompt: please say what you are looking for or what you are trying to do when something is unclear.
