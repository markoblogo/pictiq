# Experimenter Guide

## Before the session

1. Open <https://markoblogo.github.io/pictiq/composer/>.
2. Prepare [observer sheet](observer-sheet.md).
3. Assign anonymous participant ID: `P01`, `P02`, or `P03`.
4. Record browser, device class, date, Pictiq/Composer version, and whether recording consent was given.
5. Do not open repository files or developer tools for the participant.

## Introduction

Use [participant instructions](participant-instructions.md). Do not teach expected task answers.

## Allowed neutral responses

| Participant asks | Allowed response | Not allowed |
| --- | --- | --- |
| "Where do I find symbols?" | "You can browse the Palette or use Search." | "Search for HOME/WATER/etc." |
| "What does this icon mean?" | "You can use the label or gloss shown in the Palette or Inspector." | "It means shelter, so choose that one." |
| "Is this correct?" | "Please finish it the way that makes sense to you." | "Yes" / "No" / "Use this icon." |
| "How do I add another part?" | "The plus button adds another Frame." | "For this task you need exactly two Frames." |
| "How do I move it?" | "You can drag symbols in the Workspace." | "Move that symbol before this one." |
| "How do I export?" | "Use Export / inspect on the right, then choose an export option." | Explaining JSON unless the task explicitly uses JSON. |

## Blocked participant rule

If the participant is stuck for about 60-90 seconds because of UI mechanics, provide neutral mechanical help and record it as an intervention. If the participant is stuck because they cannot decide which concept expresses the task, do not provide the answer; record the friction.

## During scored tasks

- Start and stop timing for each task.
- Record first action, searches, context switches, concepts considered, wrong selections, corrections, reorder actions, Frame actions, diagnostics, help, final message, final Renderer output, confidence, and notes.
- Do not correct the participant during the task.
- Think-aloud is optional; do not repeatedly interrupt.

## After the session

Ask [debrief questions](debrief.md). Store notes without unnecessary personal data. If recording was used, store it only according to the participant's consent.
