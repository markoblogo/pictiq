## Book and purpose

*No Further Claims: A Bracken Ford Novel*. Four black-and-white full-page comics combine conventional drawn narrative with Pictiq Composer output. The complete visual system is one non-Pictiq frontispiece, four Pictiq narrative inserts, and one non-Pictiq closing illustration.

The case asks whether existing Pictiq vocabulary can encode selected simplified semantic statements for editorial use. It does not claim that Pictiq translates the novel, replaces prose, or functions as a speech-balloon language.

## Production workflow

`narrative scene → simple English semantic sentence → Pictiq Composer → Composer-rendered sequence → comic artwork → sequence integrated into comic`

The sequences were authored through Composer, not generated by the image model. The supplied final images are composite editorial artwork containing drawn narrative and integrated Pictiq sequences.

For every comic, preserve three distinct layers: **NOVEL SCENE**, **COMPOSER INPUT**, and **PICTIQ OUTPUT**. The Pictiq layer encodes the selected semantic layer, not the entire literary scene.

## Comic 1 — Original Incident

### Novel Function

Incident → observation → uncertainty → communication → investigation → record.

### Composer Input

1. “A boy sees a dog and a large bird near a gas facility.”
2. “A woman sees danger but does not know what happened.”
3. “People talk about what happened. They are not sure.”
4. “Police observe the place and write a report.”
5. “The report says what is known. Some things remain unknown.”

### Pictiq Output and panel mapping

The retained visual sequence is sufficiently distinct at the semantic level:

1. boy sees dog + large bird + gas facility
2. woman sees danger + unknown
3. people communicate about event
4. police observe + write/report
5. report + communication/knowledge state

## Comic 2 — The Eagle Trail

### Novel Function

Old record → proposed useful path → historical/public-story conflict → refusal → unresolved civic problem. This is the transition to adult Eli’s main line.

### Composer Input

1. “A man reads an old record.”
2. “People want a new path through the town.”
3. “The old story and the record are different.”
4. “The man does not agree.”
5. “People want the path, but there is a problem.”

### Editorial visual brief

Adult Eli in the archive → trail project → Mrs Bell / town support it → old report against the attractive public version → Eli refuses to sign. This corresponds to the novel’s central conflict.

## Comic 3 — Who Owns the Story?

### Novel Function

Multiple memories/accounts → withholding → correction → bounded institutional statement → public disagreement. This tests competing knowledge states rather than a single event.

4. “Police say only what they know.”

## Vocabulary / grammar changes

No vocabulary or grammar change was made specifically to enable these comics. No post-hoc correction is proposed.

## Observed limitations

Bounded observations: existing vocabulary was used for four simplified narrative inserts without a case-specific addition; richer literary relations still require drawing and context; Composer can function as an intermediate authoring tool for editorial inserts. These are **OBSERVED IN THIS CASE**, not universal validation.

Potential weak relations include uncertainty, evidential status, rumor, official correction, causality, identity continuity, secrecy, and withheld knowledge. Classify each later as composition, drawing-carried, lost/weak, or change candidate only from preserved output and testing.

## Editorial micro-language hypothesis

This use suggests a possible editorial micro-language: drawing provides concrete scene/world/identity, Pictiq provides compact abstract semantic structure, and prose provides the literary work. This remains a hypothesis, not formal Pictiq positioning.
