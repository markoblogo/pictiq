# Good Dog, Bad System — Case Learning Record

**Scope:** observations from one prepublication fiction-production case only. These notes do not generalize to Pictiq comprehension, commercial success, or all long-form fiction.

1. Pictiq can be used as an in-world narrative language for direct canine communication inside a full-length English novel.
2. A stable distinction—dog communication in Pictiq, human speech in English, system notices in system typography/English—gives the production a consistent convention without requiring explanatory prose in every scene.
3. Composer output must remain authoritative and immutable through illustration composition.
4. Generative illustration can create scene artwork but must not generate or imitate exact Pictiq glyph sequences; identity, order, speaker, and dialogue can drift.
5. Final composition needs speaker-level dialogue provenance. The owner-corrected GD1 semantic reference also shows why dialogue/source numbering must be reconciled against the actual production sequence before ledgering.
6. Preserve Pictiq source sheets separately from flattened final book illustrations.

## Workflow friction observed

The supplied Composer source sheets do not contain stable per-turn block identifiers, machine-readable semantic text, speaker metadata, or placement links to final panels. Future production could retain those fields in an export/provenance manifest. This is a product observation only; Composer was not changed.

## Limits

The case records approved dialogue and retained image assets. It does not establish reader comprehension, reduced translation cost, sales effects, broad expressive coverage, or unique/first-of-kind publication status. No lexicon candidate is made from visual interpretation.
