# Historical corpus analysis — descriptive only

[`corpus-analysis.json`](corpus-analysis.json) contains reproducible counts over the 81 deduplicated exact records in this harvest. The denominator is the retained historical sample, not all Pictiq uses or user needs. Source selection is uneven (for example, Road/Wayfinding and Web/UI are structured research sets), so token frequency and length must not be interpreted as demand, coverage, or comprehension.

The report counts token occurrences, ordinary primitives, entities, pragmatic quantity tokens, formal numeric values, record lengths, frame counts, and mode applicability; it also lists registered primitives absent from this sample. A token being absent here is not a vocabulary gap. A frequent token is not a recommendation to change the Lexicon. No statistical test, generalization, or new protocol claim is made.
