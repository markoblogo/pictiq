# Stress Test 06B — Independent Visual Protocol Design

**Status:** `INDEPENDENT PROTOCOL ANALYSIS COMPLETE / READY FOR HUMAN REVIEW`

Stress Test 06B reverses neither icons nor phrases: three systems received a practical communication problem and designed an entire visual-protocol architecture before Pictiq was disclosed. The record separates that independent work (Phases A–C) from Phase D comparison. Phase D is not counted as convergence.

## Finding

All three systems favored a limited core, composition and deterministic machine representation. Each also put substantial meaning into learned conventions: typed frames, fixed slots, spatial attachment, containment, scoped operators or AST-like structures. Their self-critiques identify the resulting risk: fewer primitives can make a system harder to infer without instruction, especially at 24–32 px.

The evidence does **not** establish which approach performs better for people. It yields a testable trade-off: Pictiq deliberately lets context, embodiment, controlled polysemy and interaction carry some meaning; the independent systems tend toward explicit intent, relation and scope. Stress Test 07 should test individual mechanisms, not whole protocols.
