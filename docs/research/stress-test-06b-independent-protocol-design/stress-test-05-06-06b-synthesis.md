## Themes by recurrence

- **05 + 06:** quantity is a live pressure. 05 uses Pictiq additive quantities in the frozen stimulus; 06 independently favors literal repetition, dots or coin grouping.
- **05 + 06B:** zero-training should not be confused with exact semantic recovery; dialogue/repair context changes interpretation.
- **06 + 06B:** small-size performance exposes counting, nesting and fine-grained conventions.
- **06B only:** explicit-grammar-versus-learned-burden is a focused architectural hypothesis.

No study supports changing Pictiq numeric notation or grammar now.
