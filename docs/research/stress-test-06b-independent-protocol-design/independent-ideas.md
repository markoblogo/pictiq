# Independent ideas not currently normative in Pictiq

These are hypotheses, not backlog commitments.

1. **Explicit semantic graph:** a machine model with typed entity, relation, property, quantity, target and scope fields.
2. **Fixed spatial grammar:** containment, fixed modifier positions, typed slots and visible operator scope.
3. **Explicit dialogue primitives:** distinct `REQUEST`, `AVAILABLE` and `WHERE` mechanisms rather than contextual recovery.
4. **Safety redundancy:** require redundant encoding for a safety-critical prohibition.
5. **Approximation metadata:** make an intentionally approximate reading visible in the message representation.
6. **Resolution profiles:** restrict composition complexity according to rendering size.
7. **Formal grammar-glyph reserve:** prevent lexical glyphs from resembling grammar marks.

None is evidence that Pictiq has a defect. The smallest next step is controlled comparison with stable pictograms and one changed mechanism.
