# Pictiq ideas not independently derived

The independent pre-reveal designs did not derive these Pictiq-specific architecture decisions:

- **Zero-intent:** a bare tile can already be a valid message.
- **Embodied versus standalone communication:** body, gaze, pointing, object and environment are available protocol surfaces in live use.
- **Catalog Grid Mode and Phrase Line Mode:** pointing and sequence are distinct canonical layouts.
- **Contextual adjacency and action-relevant polysemy:** relation can remain deliberately contextual when it preserves the required decision.
- **Meaning-before-wording, priority-first communication and functional sufficiency.**
- **Intentional omission versus LOSSY and GAP.**
- **Scoped Entity Symbols** with provenance, authority and namespace.
- **Parameters and profile selection** rather than reflexive lexical expansion.
- **Flat-message discipline, canonical renderer, validators and multi-size QA.**

These differences explain why a small Pictiq phrase need not carry all information that the independent protocols attempted to encode structurally.
