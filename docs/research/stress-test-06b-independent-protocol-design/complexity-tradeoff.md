# Complexity trade-off

## Thesis

A small primitive inventory does not automatically reduce what a recipient must learn. Complexity can move from the lexicon into spatial syntax, operator scope, layout orientation, numeral conventions and repair protocol.

| System | Initial → final core | Explicit grammar / conventions | Main structural load |
|---|---:|---:|---|
| ChatGPT | 22 → 23 | 9 final rules | scoped operator frames, modifier slot, containment, quantity compartment, direction/transfer, safety redundancy |
| Claude / Trace | 36 → 32 (corrected from “about 40”) | 22 grammar + 3 rendering rules | header/mood, typed cells, slot order, top/bottom contact, containment, groups, slash scope, numeral tiles |
| Gemini | 28 → 23 | typed frame classes plus LTR sequence, connectors and operator frames | entity/action/quality/operator frame taxonomy, structural links, separate negation/prohibition |
| Pictiq | 87 ordinary canonical tiles; 16 Entity Symbols separate | flat phrase rules, 1–3 recommended / 5 maximum tiles | context, mode, action-relevant polysemy, terminal punctuation, pragmatic quantity and repair |

The counts are not a comparative score: primitives, frame classes, operators and rendering conventions are different units. The useful metric for a future study is **conventions a recipient must infer or learn**. Test the same meaning with one mechanism changed and distinguish blind interpretation from learned performance.
