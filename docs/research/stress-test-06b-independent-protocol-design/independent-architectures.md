# Independent architectures — Phase A only

| Dimension | ChatGPT | Claude / Trace | Gemini |
|---|---|---|---|
| Goal | short practical visual protocol, not a natural-language replacement | small visual protocol with explicit mood and repair | closed, language-neutral visual protocol with deterministic parsing |
| Initial core | 22 semantic primitives | stated “about 40”; later corrected to 36 | 28 foundational visual elements |
| Main grammar | frames, center/outward reading, containment, modifiers, directed relations | message header, typed cell shapes, slots, contact, containment and groups | typed frame geometries, LTR subject–action–object, attachments and compound frames |
| Composition | spatial containment and modifier positions; directed arrow | seven spatial operators and up to two nesting levels | top-right modification, enclosure, directional vectors |
| Questions | initially `?` plus PRESENT/AVAILABLE; later recognized ambiguity | ASK mood, typed empty slot, yes/no pair | QUERY operator around statement |
| Quantity | 1–5 literal marks, external numeric layer beyond | dots plus ten-slot digit frames | tally bars/strokes and base-ten grouping |
| Names / unknown | external references and arbitrary identifiers | category plus opaque literal payload; declared gap | person/location plus physical reference; approximate boundary |
| Machine strategy | semantic tree / graph | typed tree and proposed binary wire format | AST/JSON isomorphism |
| Governance | compose first; lexicalize after evidence of composition failure | hard core cap, registry, ad hoc tier | frozen 28-item core; no ad-hoc icons |

All three pursue compact vocabulary through explicit structure. That shared premise is the experiment’s main independent result, not evidence that their visual grammar works without learning.
