# Method

Stress Test 06 asks the reverse of Stress Test 05: starting from the same practical dialogue and minimal visual constraints, what reusable symbols do generative systems independently produce?

Analysis proceeds in this order: (1) task completion and constraint compliance, (2) actual visual metaphors, (3) quantity and composition, (4) vocabulary reuse in Phase 3, and only then (5) comparison with Pictiq. Textual explanation is never treated as proof that an image successfully communicates its stated design.

The dataset is asymmetric. ChatGPT and Gemini offer image, explanation, and reuse output. Copilot offers a textual design only. Ideogram provides four visual candidates for each applicable phase but no explanation. Leonardo.Ai provides one weak Phase 1 image only. These are capabilities of this run, not claims about products generally.

No system was re-run; no image was regenerated; no Pictiq asset or protocol file was changed.
