source of the 654px document width.

## Minimal source fix

Changed only the ordinary Dictionary Viewer CSS in
[the existing generator](../../../tools/research/build_composition_dictionary_baseline_v0_1.py):

```css
.entry { grid-template-columns: minmax(240px,420px) minmax(0,1fr); }
.entry > div { min-width: 0; overflow-wrap: anywhere; }
@media (max-width:700px) {
  .entry { grid-template-columns: minmax(0,1fr); }
}
```

Existing spacing, fonts, image containment and pre/code rules are retained. Long
text now wraps and grid children can shrink. There is no `overflow-x: hidden`,
ellipsis, scaling, text deletion or new scrolling container. Computed html/body
`overflow-x` remains `visible`; History's `pre` remains `pre-wrap`. The generated
Viewer differs only in its style block; its embedded data and JavaScript are
identical to the starting revision.

Regeneration changes only `review/index.html` and its digest in the active
`manifest.json`. No other generated artifact is changed.
