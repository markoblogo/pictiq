## Готовность и оставшиеся границы

Готовы к отдельному применению: четыре правки описаний/контекста (`0002`, `0006`, `0009`, `0030`), контекстный выбор preferred и сохранение трёх допустимых форм (`0028`), исключение Dictionary-проекции с сохранением Corpus (`0025`) и применение ранее одобренной отдельной timetable-записи из addendum (`0065`). Четыре `ACCEPT_AS_SHOWN` сохраняют существующие Messages и пояснения; само принятие не требует придумывать исправления.

Неопределённости не блокируют эти минимальные действия: точный ID для необязательной «иконки места» и для примера «ремонт» не задан; отдельное изменение `comm_speak`-вариантов не предписано; новое значение `message.profile` для медицинского примера не задано. Постоянный ID timetable — техническое назначение в проходе применения, не новый смысловой выбор. Эти детали не заполнять догадкой.

**Отдельно от Dictionary:** пояснения затрагивают возможные описания примитивов `comm_sound`, `place_shop`, `move_feet`. Их будущую сверку с [Lexicon](../../../../lexicon/icon-index.json) следует рассматривать отдельно; этот пакет не изменяет реестр и не поручает его автоматическую правку. Контекстные LESS/DOWN, AUTO/NO и экономия указания на человека не становятся общими правилами Grammar/Protocol.

**Резерв С01.11 — только `comm_sound` (2026-11-19):** read-only сверка обнаружила расхождение полного определения с авторским `/records/2/creator_note`. В [Lexicon](../../../../lexicon/icon-index.json) у `comm_sound.meaning_en` записано `sound / audible signal / music / what is heard`, а `aliases_en` — `sound`, `audio`, `audible signal`, `music`, `heard`. [Данные Composer](../../../composer/generated/pictiq-composer-data.mjs) повторяют это определение; [tokenLabel](../../../composer/composer-core.mjs) возвращает `meaning_en`, и [интерфейс Composer](../../../composer/app.mjs) использует его в подписи палитры и подсказке выбранного знака (`sound / audible signal / music / what is heard · comm_sound`). Полная формулировка ограничена слышимым и не обозначает человеческий источник: письменная коммуникация и соцмедиа не отражены, природные и животные звуки не исключены. Одно короткое название `Sound` само по себе не основание вывода. Это отдельная будущая правка определения/подсказки; реестр, данные и код Composer в С01.11 не изменены. Другие примитивы не сверялись.
