# Partial results analysis

## Status

This is a **partial Phase 1–2 collection**, not a completed Stress Test 07 result. The frozen protocol requires blind interpretation, practical action, micro-learning and learned transfer. The supplied material ends after the blind/practical sequence. **Pilot status:** `INVALID / PARTIAL FOR PRIMARY STRESS TEST 07 INFERENCE`.

Three of five runs were source-exposed. The remaining two are treated as exploratory visual evidence only; ChatGPT's `07C-A` reports a no-smoking sign, incompatible with the frozen toilet-plus-question stimulus, so that observation is excluded for that item.

## What the data do and do not show

1. Raw SVG delivery cannot support a blind-comprehension claim because semantic metadata leaked to three systems.
2. The current additive quantity expression was not recovered exactly by the two usable visual candidates. This is a hypothesis about blind learnability, not a reason to change Pictiq grammar.
3. The explicit location mark produced the clearest clean recovery. It remains a hypothesis pending a controlled, fully phased rerun.
4. The experimental availability grammar did not resolve available versus wanted, needed or confirmed in the usable replies.
5. No learned-transfer result exists, so the study cannot answer whether any explicit mechanism becomes preferable after instruction.

## Next controlled collection requirement

Do not alter this frozen experiment. If a repeat is authorized, create a distinct delivery package that (a) provides pixels rather than semantic SVG source, (b) verifies the image rendered for each participant, (c) completes micro-learning and transfer, and (d) preserves each model transcript separately. Only then pool outcomes by the pre-registered coding rules.

No production Pictiq semantics or assets are changed by this analysis.
