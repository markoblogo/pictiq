# Human-testing adaptation

The frozen package can later support human testing without changing stimuli.

1. Do not mention Pictiq before the blind phase.
2. Show one individual SVG at a time and record the first interpretation verbatim.
3. Ask the matching practical-task prompt.
4. After the blind block, provide only the matching micro-learning rule.
5. Show the corresponding new transfer stimulus.

This package does not recruit participants, collect consent, or claim that AI responses substitute for human evidence.
