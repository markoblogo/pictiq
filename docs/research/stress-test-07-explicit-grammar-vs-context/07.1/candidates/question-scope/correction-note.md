# Explicit question-scope candidate note

Human pre-execution review identified a visual-scope confound in the experimental explicit-question condition: the question mark entered the semantic object's visual field and could read as part of a composite object glyph.

Each candidate keeps the existing outer scope container and moves `?` into a distinct header/operator zone. The unchanged 160×160 object tile moves from `y=48` to `y=80`; its artwork, size and horizontal position are unchanged. AVAILABLE and WHERE remain in their existing external positions. This is a pre-execution stimulus-design correction, not post-result optimization.

Candidates are internal review artifacts only. They do not replace frozen sources, delivery PNGs, hashes or manifests until human acceptance.
