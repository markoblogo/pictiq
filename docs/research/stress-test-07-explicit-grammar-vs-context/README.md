# Stress Test 07 — Explicit Grammar vs Contextual Compression

**Status:** `PILOT INVALID / PARTIAL DATA PRESERVED / 07.1 RERUN PREPARED`

Stress Test 07 is a controlled mechanism study following Stress Tests 05, 06 and 06B. It does not compare Pictiq with a competing language. Each pair changes one representation mechanism while holding the practical meaning and reusable Pictiq object artwork constant wherever possible.

## Question

> How much explicit visual grammar improves semantic precision before the additional grammar itself becomes something an untrained recipient must learn?

## Primary comparisons

- **07A Quantity:** current Pictiq `need_water + qty_1 + qty_2` versus three literal marks.
- **07B Availability:** current Pictiq `need_water + punct_question` versus experimental QUESTION-SCOPE + AVAILABLE.
- **07C Location:** current Pictiq `need_toilet + punct_question` versus experimental QUESTION-SCOPE + WHERE.

The six participant-facing SVGs contain no Pictiq name, condition label, English explanation or legend. Review sheets are for researchers only and must not be shown in blind testing.
