# Portable layouts

## Carriers

The repository contains shirt, wallet-card, lighter, luggage-tag, and phone-lockscreen layouts.

## What they taught

Each carrier changes available area, reading distance, hierarchy, and the balance between primary and secondary/contextual icons. Profiles keep semantic selection reusable while layouts adapt the physical representation.
