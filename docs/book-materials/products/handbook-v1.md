# Handbook v1

## What it was

Handbook v1.0 was the first complete illustrated public entry point for Pictiq, published as PDF and EPUB.

## What it taught

It established a readable project frame spanning protocol rules, context packs, portable layouts, storytelling, and machine-interface ideas.

[Handbook directory](../../../books/handbook-v1/), [release note](../../../releases/handbook-v1.0.0.md), [PDF](../../../books/handbook-v1/pictiq-handbook-v1.0.pdf), [EPUB](../../../books/handbook-v1/pictiq-handbook-v1.0.epub).

## Boundary

Later Embodied/Standalone architecture, Batch A, and perceptual-QA changes belong to later records. Handbook v1.0 is not retroactively revised by this archive.

## Future use
