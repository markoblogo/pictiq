# Parametric color

## Core observation

Arbitrary color values cannot be faithfully represented by a finite set of monochrome lexical symbols.

## How it was discovered

The standalone analysis contrasted pointing to an actual color in embodied use with a remote or printed instruction that must preserve the value.

## Evidence

[Protocol color proposal](../../../spec/PROTOCOL.md#12-communication-primitive-classes), [backlog](../../../spec/STANDALONE_BACKLOG.md#parametric-color-prototype).

## Current status

**PROPOSED PARAMETRIC MECHANISM — NOT IMPLEMENTED.** Conceptual values include `color(#747b72)`.

## Unresolved questions

Syntax, machine representation, contrast, print behavior, and accessibility need testing.

## Potential book angle

When a visual language needs a value, not another word.
