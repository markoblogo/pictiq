# Constrained Visual Writing Framework

> Status: research / book-material framework
> Source event: Pictiq Research Foundations — Batch 03
> Scope: expressive-writing research only; no grammar or Renderer semantics change implied.

## Central question

Pictiq poetry should not primarily be judged by its ability to translate ordinary verbal poetry into icons. The stronger question is:

> What forms of writing become possible because Pictiq is constrained?

## Pictiq-native poetic resources

| Resource | Possible poetic role |
| --- | --- |
| Repetition | visual meter / refrain |
| Silhouette relation | visual rhyme |
| Gap | silence / absence |
| Polysemy | resonance |
| Context Pack | register |
| Entity Symbol | leitmotif |
| Intentional omission | formal absence |
| Transformation | development |
| Order / grid | visual form |

These are research concepts, not normative language semantics.

## Strict mode vs poetic mode hypothesis

Strict / protocol writing prioritizes validity, stable reading, interoperability, and deterministic parsing.

Poetic / expressive writing may deliberately use ambiguity, spacing, repetition, scale, visual echo, omission, and multiple readings.

This difference may require future mode labels or publication conventions, but this pass does not add protocol modes, schema fields, layout semantics, or new grammar.
