# Profile layers

## Core observation

Embodied and Standalone Profiles select from one canonical lexicon. They are recommendations for communication mode, not duplicate icon libraries.

## How it was discovered

The Embodied/Standalone distinction showed that live body, gesture, gaze, environment, and pointing can supply concepts that durable artifacts must encode explicitly.

## Evidence

[Profile specification](../../../spec/PROFILES.md), [Embodied profile](../../../profiles/embodied-core-v0.1.json), [Standalone profile](../../../profiles/standalone-core-v0.1.json).

## Current status

Both profiles are v0.1 recommendations. Context packs can layer on either; Standalone is intentionally incomplete pending Batch B and protocol prototypes.

## Unresolved questions

Profile boundaries need task-based evidence across real carriers, websites, signs, and narrative.

## Potential book angle

One vocabulary, multiple communication surfaces.
