# Context Economy and Common Ground

> Status: research concept / book-material note
> Source input: [`../research/inputs/perplexity-2026-09/context-economy-in-communication.md`](../research/inputs/perplexity-2026-09/context-economy-in-communication.md)
> Rule: explanatory framework only; no scientific validation of Pictiq is claimed.

## Core idea

Context economy means that communicators can encode less explicitly when the environment, shared task, prior knowledge, interface state, or social situation already carries part of the message. This helps explain why a small visual protocol may work better in some situations than a dictionary-sized one.

The idea connects to several theoretical traditions that need verification before book-public use: Gricean pragmatics, Relevance Theory, deixis, common ground, Peircean indexicality, Shannon conditional entropy, ecological interface design, context-aware computing, affordances, wayfinding placement, gesture, situated action, and procedural communication.

## Ambient vs declared context

| Type | What it is | Pictiq examples | Risk |
| --- | --- | --- | --- |
| Ambient / situational context | Meaning supplied by visible objects, pointing, gaze, shared location, immediate interaction, live Embodied communication. | Pointing at a bottle while using `need_water`; showing `punct_question` while standing at a station; using `rel_here` in a shared location. | Breaks when sender/receiver do not share the same physical or interaction context. |
| Manufactured / declared context frame | Meaning supplied by a chosen domain, Context Pack, professional terminology, procedural phraseology, CAP-like schema, trained domain vocabulary, standardized task profile. | Road pack, medical appointment profile, Odyssey entity context, future airport or shelter pack. | A declared context can constrain interpretation, but it does not automatically create common ground. |

## Key conclusion

A Context Pack does not automatically create common ground.

A Context Pack may constrain vocabulary and interpretation, but users still need enough shared knowledge, training, interface cues, or situational context to decode it reliably. This is especially important for tourists, migrants, humanitarian use, AAC-adjacent use, public information, and safety/medical contexts.

## Implications for Pictiq

- Embodied use can offload meaning to gesture, location, gaze, and shared objects.
- Standalone use needs more explicit composition, labels, context frames, or training because ambient context is weaker.
- Context Packs should be treated as declared constraints, not magic disambiguators.
- Cross-cultural comprehension cannot be assumed from pictorial appearance alone.
- Human experiments should test whether context actually helps users decode a message, not merely assert that context would help.
