# Adoption and infrastructure

## Core observation

Visual communication systems do not spread merely because their icons are good.

The [comparative visual-language review](../research/from-pictographs-to-protocols.md) identifies recurring conditions: a sharply specified use case; institutional or technical distribution; repetition and training; governance and maintenance; and compatibility with existing language and communication channels.

For Pictiq, these are questions for future evaluation across repository versioning, the website, font and rendering layers, navigation adapters, books, physical products, narrative use, and machine interfaces. This is a research lens, not a marketing roadmap.
