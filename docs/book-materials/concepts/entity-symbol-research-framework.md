# Entity Symbol Research Framework

> Status: research framework
> Source event: Pictiq Research Foundations — Batch 03
> Scope: does not replace the current Entity Registry format.

## Core distinction

A lexical concept is not an entity reference.

`PERSON` means a reusable category. An Entity Symbol means this particular referent inside a declared context or namespace.

The visible Entity Symbol is a rendering/reference handle, not the identity itself. Keep three layers distinct:

1. visible mark;
2. human-readable name / label;
3. stable machine ID.

This fits the existing Pictiq Entity Symbol architecture and does not require a registry change now.

## Comparative precedents

| Precedent | Useful lesson | Boundary |
| --- | --- | --- |
| Sign-language name signs | Naming can be socially situated and consent/community-based. | Not equivalent to Pictiq; communities differ. |
| Heraldry | Visual differentiation, registry, lineage, and identity marks. | Historically specific; not a universal identity model. |
| Logos / trademarks | Learned stable associations, distinctiveness, collision/governance. | Legal trademark systems are outside Pictiq. |
| Cartography | Category symbol differs from exact named/located entity. | Maps add coordinates and labels. |
| Religious iconography | Recurring associative attributes aid narrative memory. | Cultural knowledge is required. |
| Pictographic / logo-syllabic writing | Semantic association can coexist with phonetic/textual disambiguation. | Pictiq is not a writing system for speech. |

## Research design categories

Preserve these as non-normative design/research categories:

- `SELF_CHOSEN`;
- `PORTRAIT_BASED`;
- `ASSOCIATIVE`;
- `COMPOSITE` where useful.

Do not add normative Entity Symbol modes unless current registry pressure requires them.

## Living-person safeguards

Future principles:

- living people choose or explicitly approve personal Entity Symbols;
- do not algorithmically derive marks from demographic identity;
- portraits require explicit consent;
- associative symbols should not impose stereotypes;
- Entity Symbols should remain context-bound unless stronger identity infrastructure exists;
- text/speech fallback should remain available;
- Entity Symbols are not legal, security, or medical identity credentials.

## Narrative convention hypothesis

For stories and teaching material:

| Use | Convention |
| --- | --- |
| First mention | Entity Symbol + name + optional role/association. |
| Reinforcement | Entity Symbol + short name/title. |
| Established context | Entity Symbol may appear alone. |

This is relevant to Odyssey, future children's narratives, visual stories, and recurring agents/characters. Do not retrofit current Odyssey artifacts in this pass.

## Future collision tests

Test near-neighbor confusion, recognition after delay, small-size recognition, monochrome recognition, association inference, perceived appropriateness, and context scope. Prefer fictional or pseudonymous entities before testing real-person identity.
