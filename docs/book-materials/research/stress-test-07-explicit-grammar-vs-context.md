# Stress Test 07 — Explicit Grammar vs Contextual Compression

Stress Test 07 is a prepared, frozen and unexecuted controlled experiment. It asks whether reducing visual vocabulary genuinely makes a protocol easier, or shifts complexity into conventions that recipients must infer or learn.

It compares current Pictiq contextual compression with minimal experimental explicit mechanisms for quantity, availability and location. It separates blind interpretation, practical task success, exact semantic recovery and short-guide transfer performance. The preparation does not claim a winner or a result; it supplies stable stimuli and pre-registered coding before testing.
