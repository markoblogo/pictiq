# Stress Test 07 — Explicit Grammar vs Contextual Compression

Stress Test 07 is a frozen controlled experiment. Its first manual pilot produced methodological evidence but is invalid and partial for A/B inference because raw SVG delivery leaked semantic internals, one visual delivery mismatched, and learning/transfer phases were not completed. A separate **Stress Test 07.1** raster-safe package is prepared for a clean rerun; it does not change the frozen semantic design.

It compares current Pictiq contextual compression with minimal experimental explicit mechanisms for quantity, availability and location. It separates blind interpretation, practical task success, exact semantic recovery and short-guide transfer performance. The raster-safe execution package records the method lesson: a visual stimulus must be separated from its machine-readable source representation in multimodal AI research. SVG is structured markup as well as an image, so rasterization may be required to isolate visual comprehension. This is not a claim about human perception. See the [experiment and 07.1 package](../../research/stress-test-07-explicit-grammar-vs-context/README.md).
