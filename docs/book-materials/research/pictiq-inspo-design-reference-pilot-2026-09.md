# Inspo design-reference pilot — 2026-09-19

**Status:** supporting landing/deployment research; no production change.

## Question and boundary

Can external design-reference tooling improve reference research for Pictiq's
unusual symbol-first landing without flattening it into a conventional landing
page? The current Pictiq page was the target. Its black-and-white identity,
glyph system, icon geometry, and symbol-first communication model were
constraints, not redesign material.

This is evidence about **design-reference workflow and reference selection for
distinctive UI**. It is not usability, comprehension, zero-training,
translation-correctness, or semantic-language evidence.

## Method and result

The external pilot used **Inspo MCP v0.1.16**, `lite` profile, comparing a
generic recommendation with targeted reference searches. Lazyweb independently
checked the same direction; its retained [Pictiq reference set](https://www.lazyweb.com/agentic-search/e501cb06-8594-4ae8-ac04-8f19931516d8)
contains three bounded composition references.

Generic recommendation was a poor fit *for this distinctive product*: it
favoured SaaS, agency, marquee-hero, conventional landing patterns, and even
inferred a dark presentation. This is not a general claim that Inspo is poor.

Targeted searches were substantially more useful: `type specimen`, `glyph
system`, and `ecosystem index`. They returned transferable structure rather
than templates:

- glyphs as primary content rather than decoration;
- strong scale contrast between primary symbol sequences and controls;
- predictable index rhythm for lexicon/system browsing;
- restrained spatial grouping; and
- preservation of Pictiq's black-and-white identity.

## Working guidance

Treat the Pictiq landing as a **type specimen / glyph system / visual-system
specimen that also functions as a website**, rather than a conventional landing
page decorated with icons. This is design/deployment guidance, not a language
semantic rule.

For distinctive Pictiq surfaces, use:

`SEARCH → INSPECT INDIVIDUAL REFERENCES → IDENTIFY ONE TRANSFERABLE PRINCIPLE → PRESERVE PICTIQ IDENTITY → REJECT TEMPLATE COPYING`

Prefer specific searches such as type specimen, glyph system, icon system,
symbol index, ecosystem index, visual-language specimen, or wayfinding symbol
system. External references may inform composition, scale, rhythm, grouping,
and information architecture. They do not govern Pictiq symbols, palette,
semantics, canonical geometry, or product behaviour.

## Status and future use

Inspo is an **optional external companion**, not a Pictiq dependency or runtime
integration. Do not create a dedicated ABVX Inspo skill yet; revisit after two
more real UI pilots establish a repeatable precise-query → inspection →
selection/rejection → principle-extraction workflow.

The pilot supports the existing publication-milestone candidate *Can a Visual
Language Explain Itself?* It creates no new publication milestone. It is
potential book material about finding structural analogies for a product that
does not fit ordinary UI categories; no chapter is drafted here.
