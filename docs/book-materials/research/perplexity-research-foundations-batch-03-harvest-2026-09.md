## Findings accepted as research scaffolding

1. **Icon performance is set-level and task-level, not a simple solid/outline rule.**  
   Status: DESIGN_GUIDELINE. Future icon work should preserve diagnostic cues, test semantic neighbors, and verify actual target sizes. The current filled silhouette direction remains accepted; this does not reopen existing icon decisions.

2. **Children can learn symbol-object and routine associations before literacy, but that is not proof of automatic grammar acquisition.**  
   Status: RESEARCH_FRAMEWORK. Kids-oriented work must separate recognition, sequence interpretation, guided production, spontaneous production, narrative inference, dialogue, and text bridging.

3. **Pictiq has an emerging thesis, but the thesis must be made falsifiable.**  
   Status: FALSIFICATION_TARGET. Claims about small Core expressiveness, composition, cross-language usefulness, broad primitives, context sufficiency, machine readability, and accessibility need baselines and failure conditions.

4. **Entity Symbols are references to unique scoped entities, not ordinary lexical concepts.**  
   Status: ALREADY_SUPPORTED / RESEARCH_FRAMEWORK. The current separation between ordinary vocabulary and Entity Symbols remains correct. Future work should test collisions, delayed recognition, near-neighbor confusion, and living-person safeguards.

5. **Constrained visual writing should be evaluated as its own medium.**  
   Status: FUTURE_LANGUAGE_PRESSURE. Pictiq poetry/narrative should not be judged only by back-translation into verbal poetry. Repetition, omission, spacing, visual echo, and polysemy may become expressive devices, but no protocol mode is added now.

## Claims that are too strong without testing

| Claim form | Problem | Safer current wording |
| --- | --- | --- |
| Pictiq proves a small visual language can communicate across domains. | Current evidence is mostly internal pilots and design analysis. | Pictiq is a testable attempt to support constrained cross-domain visual communication. |
| Composition is intuitive. | Users may memorize examples but fail unseen combinations. | Composition is a central hypothesis requiring transfer tests. |
| Visual symbols overcome language barriers. | Icons can be culturally variable and context-dependent. | Pictiq may reduce some language burden in bounded contexts when tested against labels, translation, and standard icons. |
| Children naturally understand Pictiq before reading. | Picture recognition is not grammar acquisition. | Children may learn staged Pictiq use with instruction and age-appropriate tasks. |
| Machine-readable visual language implies camera/vision readability. | Digital ID recovery and optical recognition are different problems. | Digital Pictiq is currently machine-inspectable; physical vision-readability is a deferred research track. |

## Hostile-review risks preserved

- `AUTHOR_CONTEXT_BIAS`: the author knows the target message and may overestimate recoverability.
- `RECOGNITION_INTERPRETATION_CONFUSION`: naming an icon is not the same as choosing the correct action or message.
- `HUMAN_MACHINE_READABILITY_CONFLATION`: digital structure, visible rendering, and optical recovery are separate.
- `SCOPE_INFLATION`: a useful bounded protocol can be overstated as a universal language.
- `GOVERNANCE_OPTIMISM`: packs, aliases, entity names, and future profiles need versioning and collision rules.

## Baseline policy

Future evidence claims must compare Pictiq against relevant alternatives where practical: natural-language text, translated text, standard icons plus labels, emoji, controlled language, structured forms, or JSON/tool-call preview. Pictiq should not be compared only against an empty baseline.

## Experiment priorities after Composer / Stress Test 04B

1. Grammar intuition / compositional learnability.
2. Cross-cultural Core recognition and interpretation.
3. Polysemy / broad primitive recovery.
4. Context sufficiency under forwarding, delay, or reduced situational context.
5. Compression taxonomy reliability across annotators.
