# Book-safe Claims and Verification Backlog

> Status: verification backlog / positioning guardrail
> Rule: Perplexity citation presence is not verification.

## Claims to avoid

| Claim | Status | Safer handling |
| --- | --- | --- |
| “Pictiq is the first visual language with grammar.” | TOO_STRONG | Say Pictiq joins a lineage of compositional visual/symbolic systems. |
| “Pictogram systems are flat dictionaries.” | TOO_STRONG | Say many public pictogram sets are lookup-oriented, but there are major compositional counterexamples. |
| “Visual icons are universally understood.” | TOO_STRONG | Say pictorial form can help but cross-cultural comprehension requires testing. |
| “Context automatically resolves ambiguity.” | TOO_STRONG | Say context helps when it is shared and recoverable. |
| “A Context Pack creates common ground.” | TOO_STRONG | Say a pack constrains vocabulary; users still need training/context. |
| “Pictiq is inherently cross-cultural.” | TOO_STRONG | Say Pictiq is designed for cross-language potential but needs empirical testing. |
| “ISO requires 85% comprehension.” | TOO_STRONG | Distinguish ISO methodology, historical criteria, ANSI thresholds, and adopting-organization criteria after primary verification. |

## Defensible research framing

These claims are more defensible, but still evidence-sensitive:

- Pictiq uses a deliberately small compositional vocabulary.
- Pictiq separates Core, context vocabulary, Entity Symbols, numeric notation, profiles, and locales.
- Pictiq now has a machine-readable Message representation and deterministic Renderer.
- Pictiq uses automated validation and compatibility metadata.
- Pictiq distinguishes Embodied and Standalone communication.
- Pictiq is developed through explicit stress tests and archived negative results.

## Book architecture themes preserved

Future book material can use these themes without finalizing chapter order:

1. Pictiq among visual languages: Blissymbolics, SignWriting, military symbology, AAC, emoji, wayfinding, visual DSLs, Icono / IKON.
2. Small vocabulary, not first grammar: avoid false novelty claims.
3. Context does part of the work: deixis, common ground, relevance, embodied communication, declared context frames.
4. When context fails: cross-cultural interpretation, migration/tourism, safety, AAC, testing/training.
5. Polysemy as compression: broad semantic roots, contextual repair, ambiguity cost, split criteria.
6. How do we know an icon works: recognition, comprehension, context-of-use, production, human experiments.
7. Growing without bloating Core: Context Packs, profiles, localization, compatibility.
