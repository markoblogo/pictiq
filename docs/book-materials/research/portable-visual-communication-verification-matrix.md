## Claims not retained as publication-safe facts

- Point It sold more than 2.5 million copies: only "over 2 million" was found in publisher/retail copy.
- Kwikpoint became standard issue for all U.S. servicemembers: only weaker first-party and secondary evidence was found.
- Kwikpoint Apple graphics laboratory / Illustrator / FreeHand origin: not verified.
- This, Please picture count and edition history: not verified.
- ICOON halal symbol: plausible for humanitarian context but not confirmed in sources checked here.
