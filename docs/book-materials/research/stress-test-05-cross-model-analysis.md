# Stress Test 05 — Cross-Model Analysis

**Status:** `CROSS-MODEL ANALYSIS COMPLETE / READY FOR HUMAN REVIEW`

Five supplied transcripts from ChatGPT, Claude, Gemini, Mistral, and Microsoft Copilot were analyzed as exploratory primary evidence. No external model call was made.

The result set separates visual recognition from Pictiq semantics. Question, affirmation, money, and card were broadly recognized. Three systems recovered a retail dialogue and recurring product; two systems read the water glyph as a pencil/writing object, so later semantic errors cannot fairly be called Pictiq-composition failures. Only one system inferred both displayed additive quantities without a guide.

The decisive finding is methodological. The supplied transcripts describe an alternate image containing `qty_2 + qty_1` and `qty_5 + qty_1`; the published frozen 05A artifact deliberately uses `qty_plus` and omits exact `3` and `6`. The results cannot be claimed as an execution of that frozen protocol until evidence provenance is reconciled.

Current grammar defines additive practical quantity composition, while Handbook v1.0 did not state it explicitly. This is a handbook/documentation candidate, not a Numeric Notation defect and not a vocabulary request. No new symbol is justified: visual recognition, guide-version, and stimulus-provenance explanations must be addressed first.

The next evidence-led action is to bind any replication to one hashed PNG, verbatim prompt, and guide version, then decide whether a new panel is warranted. Stress Test 05 is not a publication milestone on this record.
