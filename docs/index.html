A tiny visual language for when words are too much.

Pictiq is an open visual language built from a small vocabulary of reusable symbols. Instead of translating words one by one, it combines familiar visual concepts, composition and context to communicate meaning across languages, situations, people and machines.

Pictiq is small on purpose.

Pictiq is a compositional visual language/protocol. It keeps the ordinary vocabulary compact, then lets symbols work together through composition, context and intentional polysemy.

It is designed for zero-training entry: a first useful exchange should not require studying the whole system first. The project is developed publicly, with the vocabulary, message format, renderer and Composer available in the repository.
