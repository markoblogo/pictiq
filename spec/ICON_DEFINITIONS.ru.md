# Pictiq Icon Definitions & Design Brief (RU)

Этот документ — ТЗ для дизайнера/разработчика иконок: что означает каждая иконка и как она должна выглядеть.
Важно: **в репозиторий попадают только SVG без `<text>`**. Если при подготовке знаков `? ! + - I II IIIII` используется шрифт, он служит лишь исходником — затем символ переводится в кривые и нормализуется вручную.

## 0. Общий стиль
- Формат: SVG, viewBox `0 0 32 32`.
- Рамка tile обязательна (rounded square), внутренние формы не касаются рамки (кроме `logic_no`).
- Цвет: `currentColor`, без жёстких цветов и градиентов.
- Стиль внутреннего знака: силуэт/заливка, без теней, без полутонов, без “контурной” графики.
- Читаемость на расстоянии вытянутой руки — ключевой критерий.

## 1. Знаки, которые можно строить от шрифта (исходник)
Эти токены допускают использование шрифта как исходного шаблона:
- `punct_question` (?)
- `punct_exclaim` (!)
- `qty_plus` (+)
- `qty_minus` (-)
- `qty_1`, `qty_2`, `qty_5` (I, II, IIIII)

### 1.1 Фиксация шрифта-исходника
- Исходный шрифт для построения: **Inter Bold**.
- После построения символ **обязательно** переводится в кривые и доводится под стиль протокола.
- В итоговом SVG не должно оставаться `<text>`.

### 1.2 Геометрические требования
- `qty_plus` должен быть заметно “худее/легче”, чем `safety_medical` (медицинский крест).
- Римские штрихи (`I`) одинаковой толщины, с равными интервалами, без декоративных засечек.
- Пунктуация крупная, центрированная, без мелких деталей.

## 2. Служебные и логические иконки

### punct_question — “вопрос”
Внутри tile крупный знак `?`, центрирован.
Смысл: “где/как/можно ли/есть ли”.

### punct_exclaim — “срочно / help / внимание”
Внутри tile крупный знак `!`, центрирован.
Смысл: “срочно / помогите / важно”.

### logic_yes — “да / ok / принято / открыто”
Внутри tile силуэт галочки (check mark).
Смысл: подтверждение, согласие, “подходит”, “открыто”.

### logic_no — “нет / не / запрет / закрыто”
Внутри tile один диагональный слэш `/`.
- направление: верхний-правый → нижний-левый
- толщина слэша: 2–3× толщина рамки
Смысл: отрицание/запрет. Используется как `X + logic_no` или как самостоятельный ответ.

### Fixed negations (устойчивые отрицания) — только контекстные протоколы
Tile с объектом/концептом, поверх которого нанесён тот же слэш, что в `logic_no`.
Правило: слэш должен совпадать по направлению и характеру с `logic_no`.

## 3. Время и количество

### time — “время / когда / расписание”
Круг-циферблат. Внутри две стрелки:
- минутная: вертикально вверх (на 12), почти до круга, но не касается
- часовая: горизонтально вправо (на 3), длиной около половины радиуса
Стрелки соединяются в центре круга.

### qty_1, qty_2, qty_5
Символы I, II, IIIII как силуэты.
“Много”: допускается `qty_5 + qty_5` и/или `qty_5 + qty_plus`.

### qty_plus — “больше / ещё / добавь”
Символ `+` как силуэт.
Критично: отличать от `safety_medical` (медицинский крест должен быть заметно “жирнее”).

### qty_minus — “меньше / убавь”
Символ `-` как силуэт.

## 4. Деньги

### money_coins — “наличные / деньги”
Две монеты с перекрытием + визуальный приём (ребро/слой), чтобы избежать ассоциации с логотипами платёжных систем.
Запрещены: валютные знаки, цифры.

### money_card — “оплата картой”
Прямоугольник со скруглёнными углами + магнитная полоса.
Запрещены: логотипы, цифры, мелкий чип.

### money_atm_bank — “банкомат / банк”
Отдельно стоящий банкомат: корпус, экран, блок 3×3 кнопки, щель выдачи.
Запрещены: буквы ATM, валютные знаки.

## 5. Связь и энергия

### comm_wifi — “Wi-Fi”
Точка + две дуги (стандартный знак).

### comm_phone — “телефон / связь”
Вертикальный смартфон со скруглением; внутри 4–6 крупных “иконок приложений” (скруглённые квадраты), без мелких деталей.

### power_plug — “электричество / розетка / зарядка”
Силуэт вилки (plug) в максимально универсальном виде, без привязки к стандартам стран.

## 6. Базовые нужды

### need_toilet — “туалет”
Базовое ядро: силуэт унитаза как наиболее узнаваемый международный символ.
Примечание: допускаются региональные варианты в контекстных протоколах (например, “floor toilet”).

### need_water — “вода”
Силуэт стандартной пластиковой бутылки с крышкой, без этикетки.

### need_food — “еда / место поесть”
Тарелка + приборы (вилка/нож), как универсальный знак.

### need_bar — “бар / напитки”
Силуэт винного бокала наполовину наполненного (уровень жидкости — ключевой маркер).

## 7. Безопасность

### safety_medical — “медицинская помощь”
Медицинский крест (силуэт), визуально “жирнее”, чем `qty_plus`.

### safety_police — “полиция / безопасность / армия”
Силуэт бейджа-щита без звёзд и текста.

## 8. Места и сервисы

### place_hotel — “отель / ночлег”
Канон: кровать (как дорожный символ места ночлега).

### place_shop — “магазин”
Канон: тележка супермаркета, без брендинга и мелких деталей.

### service_tools — “ремонт / сервис”
Один гаечный ключ по диагонали, ручка уходит вниз/в сторону, без мелких зубцов.

### place_disco (optional) — “клуб”
Диско-шар с крупными плитками без мелкой сетки.

## 9. Пакеты и кандидаты
- Утверждённые слова находятся в `lexicon/icon-index.json` и в packs.
- Идеи новых слов — в отдельном списке кандидатов (см. будущий `lexicon/candidates.json`).
